# Easy I18n | 專業多語言管理工具

## 1、產品概述
多語言在地化是全球化應用研發與營運的必備環節，然而長期以來普遍存在維護繁瑣、效率低落的問題。開發人員若要修改單一翻譯內容，往往必須在多個分散的語言檔案中逐項搜尋、編輯相同文字，不僅耗費時間，也容易產生錯誤。營運人員維護多語言的應用商店介紹、應用名稱、更新日誌及宣傳文案時，同樣缺乏統一管理機制，只能在不同語言檔案中重複編輯。

**簡易國際化工具（Easy I18n）** 是一款輕量級、跨平台的多語言詞條管理工具，專為解決上述痛點打造。本工具整合多語言詞條的編輯、翻譯、維護與數據統計完整流程，適用於研發與營運各類場景，能大幅提升在地化作業效率，減少重複性人工操作。

## 2、解決核心痛點
- **優化研發作業**：無須在多個獨立語言檔案中手動搜尋、修改同一詞條。僅需單一操作，就能完成該詞條所有語言版本的編輯與更新，一鍵套用生效。
- **優化營運作業**：為應用商店資料、官方介紹、更新日誌、宣傳文案等多語言營運素材，建置統一管理平台，整頓零散的語言檔案。

## 3、核心功能
### 1. 跨平台相容
全面支援 macOS、Windows、Linux（Ubuntu）等主流桌面作業系統，不同裝置的研發、營運人員皆能享有一致的使用體驗。

### 2. 多專案、多格式全面支援
可同時建立並管理多個獨立的多語言專案，相容市面上絕大多數主流開發與在地化檔案格式，包含 Android、iOS、Flutter、跨平台 Kotlin、Java 屬性檔、自訂 YAML 與 JSON 檔。每種格式可設定多組儲存路徑，對應複雜的專案目錄結構。

### 3. 簡潔高效的編輯介面
設定專案路徑後，工具會自動掃描並載入所有多語言詞條，以清晰表格呈現，每一列對應一組詞條。點擊任一詞條即可開啟整合編輯視窗，在單一頁面完成該文字所有語系翻譯的修改，不需來回切換、逐檔編輯。

### 4. 完善的篩選、排序與搜尋功能
內建全文關鍵字搜尋、多維度語系篩選、自訂排序等實用功能，可快速找到目標詞條、視覺化整理資料，輕鬆管理數千筆多語言內容。

### 5. 智慧自動翻譯
串接多款主流官方翻譯介面與人工智慧翻譯服務，開箱即可使用，支援批量詞條一鍵自動翻譯。使用者可為專案或單一詞條新增備註與補充說明，協助 AI 翻譯引擎參照前後文意，輸出更規範、貼合場景的譯文，提升翻譯精準度。

### 6. 視覺化翻譯數據統計
即時顯示視覺化翻譯進度，清楚呈現詞條翻譯完成率、未翻譯內容等關鍵數據，讓團隊直觀掌握整體在地化進度，妥善規劃後續作業。

## 4、應用場景
- **研發在地化**：行動裝置、跨平台專案日常多語言詞條的新增、刪除、修改、查詢，支援自動同步並寫回原始資源檔案。
- **營運在地化**：統一維護多語言應用商店文案、應用名稱、版本更新日誌、品牌宣傳文案等營運資料。
